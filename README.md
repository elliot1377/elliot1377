# Hey, I'm elliot 👋

**Build what others think is impossible.**

I work on bringing classic Call of Duty and console games back to life: private servers, modding tools,
and emulator work for Xbox 360, PS3 and PS5 titles.

## 🔥 Featured project

### [mw2-ps3-server](https://github.com/elliot1377/mw2-ps3-server) ⭐ 72
A community DemonWare server for **Call of Duty: Modern Warfare 2 (PS3)**. Play MW2 online again,
in RPCS3 or on a real PS3.

- 🔓 **PS3 / RPCS3 online bypass**: gets around the dead official servers so MW2 matchmaking works again
- 🖥️ Works on RPCS3 and on real PS3 hardware

## 🎮 Projects I work on
